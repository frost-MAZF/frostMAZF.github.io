HTB第11赛季Reactor破解流程

发表于2026-05-29|更新于2026-07-07|计算机网络渗透测试
|总字数:607|阅读时长:2分钟|浏览量:

介绍

Reactor在HTB上标注的是easy难度，说明相较very esay难度，对于我这样的新手而言是提升较大的。

初始流程

首先我们需要启动机器并复制IP地址，在自己的虚拟机里安装openvpn接着，例如：
sudo apt install openvpn

安装完成以后，需要连接上HTB的网络，这时候需要点击右上角的Connect，接着点击Machines，然后点击openvpn，接着点击Download VPN就会下载一个后缀为 .ovpn的文件，传输进虚拟机里，接着输入下面的命令

sudo openvpn filename.ovpn

正题

首先我们使用nmap扫描一下端口开放。
sudo nmap -sS yourIP


可以看到出现了两个服务，一个是ssh，驾驶现在不知道另一个ppp服务是什么，搜索端口和服务这两个关键词之后得知这是一个常用的网页端口。那么我们就试着访问一下。


可以看到一个界面，访问的时候如果无法进入，注意输入端口以及将https更改为http，如果还不行，查看openvpn是不是断连了。

接着F12,点击Network选项，File下选择/可以看到后端架构是Next.js。


接着点击Console，输入next.version即可得知next.js的版本以及使用了RSC。


接着在js文件里可以看到使用了 React，那么我们通过搜索next.js 和 React 两个关键词可以找到一个CVE-2025-55182的漏洞，也被称为 React2Shell。

接着检索可以发现已经有人写好了PoC：

  • React2Shell (CVE-2025-55182)
  • ThemeHackers/CVE-2025-55182

我们先clone仓库

git clone https://github.com/ThemeHackers/CVE-2025-55182.git

cd到仓库接着运行：

python3 CVE-2025-55182.py -u  --exploit

接着ls会发现有一个reactor.db的文件，这是一种数据库我们，我们使用SQLite datebase browser打开可以看见：


我们使用cmd5进行密码破解，得知了密码为reactor1

接着使用ssh连接到用户

ssh engineer@your IP

输入密码后，发现本地的9229端口打开了一个node的服务，经过搜索后发现是一个调试端口。

curl http://127.0.0.1:9229/json

然后就可以看见debugger url了

经过搜索后发现node.js支持远程调试，使用远程调试即可。
